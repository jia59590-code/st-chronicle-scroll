# 纪行手记 · Chronicle Scroll (SillyTavern 扩展插件)

全景沉浸式动态状态栏、伴侣深层心境与奇遇罗盘扩展插件。

---

## 核心特性

1. **零配置提示词注入 (Prompt Injection)**
   - 彻底告别繁琐的世界书配置！插件在发送对话请求前，自动拦截并向大模型下发手记输出格式规范。
   - 任意现存的角色卡、任意新会话，装上插件即可直接唤醒 7 联手记。
2. **楼层正文自动洁净 (Hide Raw Tag)**
   - 自动拦截并提取 `<fantasy_scroll>` 数据，正文楼层自动洗净或替换为轻量小标记，保持纯文学沉浸感。
3. **双官方词库内置**
   - **艾欧泽亚传奇 (Eorzea)**：高魔古典奇幻冒险，以太流向、古代灵庙迷宫、荒野晶鱼野炊、星尘水豚萌物、营火旧梦。
   - **都市漫游录 (Modern)**：现代甜蜜生活日常，沿海公路漫步、宜家样板迷宫、盲盒探宝、雨夜自制部队锅、霸道流浪胖橘。
4. **极度人性化的零代码词库工坊**
   - **拒绝改代码**：插件设置面板提供全可视化的卡片增删界面；
   - **一键删词与即时添加**：直接点击“删除”即可移除词条，输入中文表单点击“添加”即可扩充；
   - **导入/导出自由分享**：支持一键导出个人专属 JSON 词库，也能导入社区玩家分享的各类奇遇包。
5. **双重视界与无痕发送**
   - 支持古典羊皮纸与暗夜视界一键切换；
   - 3D 伴侣深层翻转卡；
   - 点击“向未知启程”、“深入迷宫”、“深夜私语”自动无痕填入对白并触发酒馆发送。

---

## 安装方法

1. 将整个 `st-chronicle-scroll` 文件夹，复制或克隆到您的 SillyTavern 安装目录下的第三方扩展目录：
   ```text
   SillyTavern/public/scripts/extensions/third-party/st-chronicle-scroll
   ```
2. 刷新 SillyTavern 网页即可生效。
3. 界面右下方将出现精致的 **【纪行手记】** 悬浮开书按钮。
4. 点击酒馆右上角“扩展设置”按钮，可进入“纪行手记 · 设置与词库工坊”进行词库定制与开关配置。

```text
├── pools/                   # 内置词库包
│   ├── eorzea.json          # 艾欧泽亚奇幻版本
│   └── modern.json          # 现代都市生活版本
├── templates/
│   ├── scroll-modal.html    # 7 联手记交互主体
│   └── settings.html        # 可视化词库管理与设置面板
└── worldbook/
    └── 世界书_纪行手记通用格式兜底.json # 独立兜底条目文件
```
